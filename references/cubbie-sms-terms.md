Program description
Cubbie sends one-time passcode (OTP) text messages to verify sign-ins. When you enter your phone number at
https://cubbie.ai/sign-in
and request a sign-in code, you consent to receive a single text message containing a one-time verification code for that request.
Verification messages are sent only in response to user-initiated requests. Cubbie does not use SMS verification consent to send marketing or promotional messages.
Message frequency
One verification message is sent per code request. Message frequency depends on how often you request a code. Message and data rates may apply.
Opting out
Reply STOP to cancel and stop receiving text messages from Cubbie. After opting out you will no longer receive sign-in codes by text message. Reply START to resume receiving verification messages.
